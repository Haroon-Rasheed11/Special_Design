# 🌐 Personal Portfolio Website

موقع محفظة أعمال (Portfolio) تفاعلي ومتكامل تم تطويره باستخدام التقنيات الأساسية للويب (**HTML, CSS, Vanilla JavaScript**). يقدم الموقع تجربة مستخدم سلسة وعصرية مع العديد من الخصائص التفاعلية التي تعزز إمكانية الاستخدام.
---

## ✨ المميزات الرئيسية (Features)
* 🌐 **دعم متعدد اللغات (Multi-Language Support):** إمكانية التبديل بين اللغات بسهولة لتحسين تجربة المستخدم.
* 🎨 **تخصيص الألوان والثيمات (Theme Switcher):** دعم التبديل بين الوضع الليلي والنهاري وتغيير ألوان الواجهة.
* 🎲 **عرض الصور العشوائية (Random Image Generator):** خاصية لتغيير واستعراض الصور بشكل عشوائي بديناميكية عالية.
* 💾 **حفظ الإعدادات (Local Storage):** حفظ تفضيلات المستخدم (مثل اللغة والثيم المختار) لتبقى محفوظة عند إعادة فتح الموقع.
* 📱 **تصميم متجاوب (Responsive Design):** متوافق تماماً مع جميع الشاشات والأجهزة (الهواتف المحمولة، الأجهزة اللوحية، والشاشات المكتبية).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **HTML5:** لهيكلة عناصر الموقع بشكل دلالي (Semantic HTML).
* **CSS3:** للتنسيق والتصميم التفاعلي ودعم متغيرات الألوان (CSS Variables).
* **JavaScript (Vanilla JS - ES6+):** للقيام بكافة العمليات التفاعلية وديناميكية الموقع بدون استخدام أي مكتبات خارجية.
